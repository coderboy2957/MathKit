# 🎮 Web Games Hub

Eine Sammlung von 22 beliebten Web- und Browserspielen, lokal aufbereitet mit einem modernen Spiele-Portal.

## 🚀 Schnellstart

Führe einfach das Start-Skript aus:
```bash
cd /Users/eliasnoesel/.gemini/antigravity/scratch/web-games-hub
./start.sh
```
Oder starte manuell einen HTTP-Server:
```bash
python3 -m http.server 8080
```
Öffne anschließend [http://localhost:8080](http://localhost:8080) im Browser.
